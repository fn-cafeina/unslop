# Hoja de ruta del producto

Este documento describe el plan de los próximos seis meses. El plan cubre el panel, la API y la facturación. Las tres piezas comparten el mismo calendario.

## Panel

El panel recibe dos mejoras: exportación programada y filtros guardados por usuario.

## API

La API gana paginación por cursor y un límite de consultas por minuto.

## Facturación

La facturación se migra al nuevo proveedor y añade facturas en dos idiomas.

## Próximos pasos

El panel, la API y la facturación avanzan en paralelo hasta junio. El plan se revisará cada mes. El panel es la pieza que marca el ritmo.
